# ExpensiveTrackerAPI

Это учебный проект проверки своих навыков. Основной фокус - это написать чистый и понятный backend с базовой архитектурой, авторизацией и работой с базой данных. В процессе планирую использовать:

- PostgreSQL
- Entity Framework
- SOLID
- Dependency Injection (DI)
- Swagger
- JWT
- Unit Testing

После завершения бэкенда сделаю простой UI, чтобы удобно протестировать основные сценарии.
